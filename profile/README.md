# ISVELORN

**A living fantasy world, rendered in a real terminal.**

Кроссплатформенная 3D ASCII/ANSI Action RPG на C — пока на стадии инженерного проектирования. Планируются процедурный мир, активные сражения, девять стихий и развитие мира с поддержкой Scheduled ChatGPT при сохранении авторитетности сервера.

[Architecture](https://github.com/isvelorn/.github/blob/main/docs/architecture.md) · [World & canon](https://github.com/isvelorn/world) · [Client](https://github.com/isvelorn/game)

> Основополагающий принцип: ИИ предлагает, проверенные системы исполняют, сервер хранит живое состояние. На данный момент система **не работает автономно**.
