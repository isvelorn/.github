## Принятые базовые границы

1. Только сервер владеет игровыми экземплярами и прогрессом.
2. GitHub хранит версии кода, канона и контента, но не живую БД.
3. Scheduled ChatGPT создаёт предложения, сервер исполняет только разрешённые операции.
4. Долговечный scheduler событий не зависит от доступности ChatGPT/GitHub.
5. Повторение `request_id` + receipt + сверка после неясного исхода, обязательные ограничения и совместимость версий.
6. Неутверждённые лор и механики нельзя автоматически повышать до канона.

## НЕ проверено и пока запрещено

- Нет живого сервера, HTTP API, реальной БД, планировщика событий, Game Client и адаптера 3D-рендеринга.
- Не проверена реальная работа Scheduled ChatGPT с приватными репозиториями, создание PR и доставка через Actions.
- Никакие secrets, auto-merge, runtime apply и production-токены **не настроены**.
- Нет branch-protection/ruleset-гарантий (GitHub App не предоставляет полный административный интерфейс).
- JSON Schema и unit-тесты не доказывают лорную непротиворечивость, баланс, приватность телеметрии или безопасность будущих API.
- Не проверены нагрузка, Unix/Windows совместимость, сбои БД, внешняя идемпотентность и реалистичная генерация региона/анимации.
