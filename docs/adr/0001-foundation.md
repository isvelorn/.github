# ADR-0001 · Разделение источников истины

**Дата:** 2026-10-17  
**Статус:** Accepted (foundation invariant)

## Контекст

ISVELORN должна развиваться через Interactive/Scheduled ChatGPT, но не зависеть от них во время обычного игрового процесса; игроки должны сохранять прогресс и возможность играть без GitHub.

## Решение

- Публичные `game` и `world` содержат исполняемый клиент и определения игрового мира.
- Приватный `server` владеет авторитетной симуляцией и БД реального состояния.
- `director` готовит ограниченные предложения, `observatory` поставляет сводки, `infrastructure` отвечает за защищённую доставку, `.github` — общие принципы.
- Git не хранит живое состояние или секреты; Git SHA закрепляет определения контента.
- ИИ не выполняет прямые произвольные операции в БД; сервер исполняет известные операции со своими проверками.
- События выполняются сервером независимо от расписания ChatGPT; повтор и восстановление — часть контракта.

## Следствия

+ Возможно отдельное развитие движка, контента, наблюдения и AI.
+ Рестарт/отключение ИИ не должны ломать базовый геймплей.
− Требуются контракты, версии и протокол доставки/квитанций.
− Самостоятельное создание *новых механизмов*, ранее не известных движку, не становится доступным автоматически.

## Изменяемые вопросы

C99/C11, конкретный renderer, данные мира/геометрия, кооператив/online, сетевые библиотеки, отдельные процессы, правила автопубликации — через новые ADR, без переписывания этого решения задним числом.
