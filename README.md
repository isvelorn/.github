# ISVELORN · Foundation

ISVELORN — проект кроссплатформенной терминальной 3D ASCII/ANSI Fantasy Action RPG с возможностью кооператива и дальнейшего развития в онлайн-мир. В перспективе мир может расширяться с помощью **Scheduled ChatGPT**, но игровая симуляция не должна зависеть от доступности ИИ.

> **Статус:** Foundation v0.1 — архитектурные контракты и проверяемые гипотезы; это не работающая игра или развёрнутая автономная система.

## Непреложные принципы

1. **Server authoritative:** клиент предлагает действия; сервер подтверждает состояние.
2. **Git ≠ игровая БД:** Git хранит определения, код и проверяемые версии; живое состояние — в защищённом хранилище сервера.
3. **AI proposes, deterministic systems execute:** ИИ не делает произвольных записей в игровую БД и не исполняет новые игровые операции, пока они не реализованы и не разрешены.
4. **Безопасный отказ:** при недоступности ИИ/GitHub игра и уже запланированные события продолжают работать.
5. **Проверяемость:** схемы → семантическая проверка → тесты → подтверждение версии → применение → квитанция → сверка.
6. **Нет обещаний без испытаний:** производительность ASCII/ANSI-рендеринга, терминальный ввод, сеть и автономные Scheduled-сессии требуют прототипов и фактических проверок.

Лор и игровые механики обсуждаются **тематически**; утверждённые определения публикуются и версионируются в `world`. Технические решения фиксируются как обычные Markdown-документы и ADR.

**Не утверждено:** окончательный рендерер, вид сетевой игры, формат постоянной карты, боевой баланс, модели генерации персонажей и объём полномочий автономных публикаций.
